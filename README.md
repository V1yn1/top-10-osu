# Top 10 performances no osu!

Página de VlNl com dez replays reais, introdução, carrossel horizontal e áudio no card ativo.

[Abrir a página](https://v1yn1.github.io/top-10-osu/)

Feita com HTML, CSS e JavaScript. No celular, toque em **Começar com áudio** e deslize para trocar de replay. Ao sair de um card, o vídeo para e volta ao começo.

[Perfil no osu!](https://osu.ppy.sh/users/32588533). Vídeos renderizados localmente com [Danser](https://github.com/Wieku/danser-go). Músicas, beatmaps e imagens pertencem aos respectivos autores.
